# Daily Practice — browser test

A privately hosted, browser-local prototype to test adding a daily habit, completing it, undoing completion, and retaining it on the same device. It does not sync between devices. Supabase authentication and database code are in the full Next.js app at `/workspace/habits`.

Install dependencies and run `npm run build` to regenerate `dist/app.js`. CSS is served from `dist/styles.css`. The static hosting manifest is `.openai/hosting.json`.
